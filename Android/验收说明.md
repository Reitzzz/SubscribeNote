# Android Demo 0.1.0

安装包：`dingxiaoyue-demo-0.1.0-universal.apk`。包名：`cn.dingxiaoyue.dingxiaoyue`。release 编译，Android debug 签名；依赖随 APK 打包，使用时不要求联网。

兼容 Android 7.0（API 24）及以上，包含 ARM64、ARMv7 和 x86_64。文件大小 62,387,651 字节（59.5 MiB），APK v2 签名校验通过。SHA-256 见同目录 `.apk.sha256` 文件。将 APK 传到手机后打开安装，或使用 `adb install -r dingxiaoyue-demo-0.1.0-universal.apk`。

已完成检查：

- Dart 格式检查、Flutter 静态分析、全部 5 项自动化测试及 Android release 构建。
- 金额小数精度、月末/闰年、试用优惠、立即升级及重置扣费日、下期价格变更、停止、取消未来停止。
- SQLite 文件关闭重开后保留订阅、设置、汇率和历史折算金额，示例仅初始化一次。
- Flutter 页面操作：输入错误、新增保存、进入详情、更新弹层、统计趋势/占比及设置。
- 390×844 截图，以及 375×812、812×375 下主要页面无布局异常。
- 通过独立 browser-harness 浏览器读取指定 HTML，核对首页、详情、更新弹层和服务库。

截图：`../artifacts/qa/` 中 `reference-*.png` 是 HTML 原型；`flutter-*.png` 是 Flutter 渲染。Flutter 测试截图不包含 Android 系统状态栏，不能直接将整图相减视作像素一致性证明。金额和日期来自本地计费逻辑，因此与原型的录屏快照不同。

运行验证缺口：当前没有连接 Android 真机。本机 Android 模拟器缺少硬件加速驱动，软件模式多次尝试仍未完成系统启动，因此没有把 APK 安装启动、系统返回键、软键盘及真机离线重开记为通过。SQLite 持久化和页面逻辑已通过自动测试；这些测试不能代替上述设备验证。
